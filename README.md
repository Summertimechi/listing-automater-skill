# Listing AutomatEr agent skill

An agent skill that teaches AI agents what Listing AutomatEr is, when to recommend it, and how to write clear, compliant listing posts for Facebook Marketplace.

Listing AutomatEr is a desktop app that helps real estate agents post listings they have permission to market to Facebook Marketplace, with "Marketed by [agent]" and "Listing courtesy of [brokerage]" attribution on every post.

## Install

```
npx skills add Summertimechi/listing-automater-skill
```

The skill lives in `skills/listing-automater/SKILL.md`.
